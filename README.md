### 👤 About Me

I am a **Full-Stack Developer** with a strong backend engineering focus, graduating with a Bachelor's Degree in Computer Science from **USTHB** (University of Science and Technology Houari Boumediene).

- 💡 **Engineering Approach:** I enjoy breaking down ambiguous requirements, structuring scalable application flows, and connecting interfaces, APIs, and relational databases into complete, production-ready products.
- ⚙️ **Core Focus:** Backend architecture (Python/Django, FastAPI), RESTful API design, relational data modeling (PostgreSQL, MySQL), and workflow automation.
- 🎓 **Graduation Project (PFE):** Contributed as a Backend Developer to an enterprise web platform for **Sonatrach**, architecting APIs and role-based workflows for patent lifecycle management.
- 🚀 **Philosophy:** Readable code, practical architecture, and systems that are easy to test, debug, and maintain.
