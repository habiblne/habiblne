### 👤 Profile Summary

> *"I enjoy turning unclear requirements into working software — architecting backend logic, designing resilient APIs, and shipping complete web products."*

I am a **Full-Stack Developer** with a specialized focus on **Backend Engineering**, graduating with a Bachelor's Degree in Computer Science (*Licence en Informatique*) from **USTHB**.

* 💻 **Backend & Data First:** Proficient in designing scalable RESTful APIs, normalization of relational schemas (**PostgreSQL**, **MySQL**), and securing endpoints with Role-Based Access Control (**RBAC**) and **JWT**.
* 🌐 **Full-Stack Competence:** Experienced building interactive web interfaces using **React**, **Next.js**, and **Tailwind CSS**, connecting them seamlessly with robust server-side architectures.
* 🤖 **Automation & AI:** Building end-to-end automated pipelines with **n8n**, integrating LLMs (**Gemini AI**), and automating data synchronization across enterprise workflows.
* 🎓 **Real-World Experience:** Engineered the backend platform for **Sonatrach** (PFE Graduation Project) to manage patent filing, lifecycle review, and IP tracking.
