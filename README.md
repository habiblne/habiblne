### 👤 About Me

> *"I enjoy turning unclear requirements into working software — designing solid backend logic, structuring clear API contracts, and shipping complete web products."*

I am a **Full-Stack Developer and Software Engineer** currently pursuing a **Master 1 (M1) in Information et Visual Computing (MIV)** at **USTHB**, where I also completed my Bachelor's Degree in Computer Science (*Licence en Informatique*).

- 🗄️ **Backend & APIs:** Designing structured RESTful APIs, relational database schemas (**PostgreSQL**, **MySQL**), and securing application workflows with Role-Based Access Control (**RBAC**).
- 💻 **Product Engineering:** Building responsive, modular user interfaces with **Next.js**, **React**, and **Tailwind CSS**, tightly integrated with robust backend services.
- ⚡ **Automation & Data:** Developing deterministic workflow automations with **n8n**, integrating AI APIs (**Gemini API**), and building data transformation pipelines with **FastAPI** and **Pandas**.
